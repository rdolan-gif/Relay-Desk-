# 15. Knowledge base


An internal library of articles that agents search and insert into replies \[SHOULD for v1\].

- **Folders:** nested tree; users' rights grant view / create / update / delete per folder (combined with the KB module access).

- **Articles:** title, rich-text body with images and attachments, tags, folder, author, last updated, version history with restore.

- **From a ticket:** "Create article" on any activity pre-fills an article draft with that activity's content.

- **In the reply editor:** a KB panel searches articles and inserts the body or a link.

- **Search:** included in global search; within the KB, filter by folder and tag.

- **Public help centre \[LATER\]:** publish selected folders to a public site.
