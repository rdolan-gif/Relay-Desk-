# 21. Open questions and sources


**Open questions for the owner** (answer before or during the phase shown)

- [ ] Single company, or sold to many companies (multi-tenant)? Decides the data model in Phase 0.

- [ ] Is telephony truly out of v1, or needed later via an existing provider (e.g. Twilio, a SIP trunk)?

- [ ] Routing rules: does the first matching rule win, or do all matching rules apply in order? Daktela's public docs do not state this. (Phase 3)

- [ ] Merge behaviour: what happens to merged-away tickets in your current Daktela use: archived, deleted, or kept as children? (Phase 2)

- [ ] Which Daktela fields, views and categories does your team actually use today? A screenshot-free list of them would sharpen sections 6–7.

- [ ] Number of agents, mailboxes and emails per day, to size the performance targets.

- [ ] Do you need data migration from your current Daktela instance (via its REST API)? If so, add a migration phase.

- [ ] Is the external portal needed in v1 or later?
